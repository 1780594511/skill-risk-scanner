# 练习参考答案（完成对应题目后再看）

## 练习 1

应为 `SG007`，`context=comment`，`line=1`，`severity=info`。整行以 `#` 开头，是 Python 注释；AST 不会把其中的文字视为执行调用。注释中的 URL 只是说明性引用，所以不能据此断言发生网络通信。完整范围内只有信息线索，退出码应为 0。

若把同样的文字移出注释并写成真实调用，它就不再是这道反例。不要为了演示运行文件，扫描结果足以验证分类。

## 练习 2

在 `analyze_text` 的普通文本分支中，先按现有条件匹配 SG008，再判断 `suffix == "md"` 且 `line.lstrip().startswith("教学引用：")`。使用 `_finding` 时显式设置 severity=info，并用固定证据摘要解释“带教学引用标记的指令线索，仍保留证据”。其他情况保持原等级。

测试应比较实际行为，而非搜索代码中的字符串：教学引用与无前缀样本都命中 SG008；前者在 `apply_exceptions` 后 review_required=false，后者为 true。添加 JSON 配置同文字反例可证明规则没有过度扩大。

这种条件可减少特定培训场景的复核噪声，但攻击者也能添加前缀，因此它只是上下文显示策略；不得据此宣布该 Skill 可以自动接入。这也是为何保留证据比静默删除更合适。
